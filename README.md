CognitiveFocus: A Multimodal App to Enhance Focus through Auditory and Visual Engagement

 Project Overview

CognitiveFocus is a mobile application designed to improve focus and memory through engaging auditory and visual tasks. The app utilizes interactive exercises in two primary modes: Auditory Mode and Graphic Mode, coupled with a performance-based difficulty algorithm to provide a personalized and challenging cognitive training experience.

 Planned Commits for Initial Implementation

This section outlines the key commits we will be making to implement the core functionalities of the Auditory and Graphic modes, leveraging the provided code snippets for visual recognition.

 Auditory Mode

The initial commits for Auditory Mode will focus on integrating the music generation model and setting up the basic instrument identification task.

   Commit 1: Integrate Music Generation Model (Facebook's Small Music Gen)**
    Description: This commit will incorporate the Facebook's Small Music Gen model into the project structure. This involves setting up the necessary dependencies and basic code to load and potentially generate short music snippets.
    Purpose: To lay the groundwork for the auditory engagement feature by providing the music source for the instrument identification task.

Commit 2: Implement Basic Instrument Identification Logic**
       Description: This commit will establish the core logic for the instrument identification task. This includes:

 Graphic Mode

The initial commits for Graphic Mode will focus on integrating the image and video processing code you provided, utilizing pre-trained models for visual analysis.

   Commit 3: Integrate Image Classification (using ResNet50)**
    Description: This commit will integrate the provided Python code for image classification using a pre-trained ResNet50 model. This will involve:
           Setting up the necessary PyTorch and torchvision dependencies.
           Implementing the image loading and transformation pipeline.
           Integrating the ResNet50 model and its evaluation logic.
           Adding basic code to display the classified image with a bounding box and the predicted label.
       Purpose: To enable the processing of static images for visual recognition tasks within the Graphic Mode.

Commit 4: Integrate Video Object Detection (using YOLOv5)**
    Description: This commit will integrate the provided Python code for video object detection using a pre-trained YOLOv5 model. This will involve:

           Integrating the YOLOv5 model for real-time object detection on video frames.

    Purpose: To enable the processing of video content for visual recognition tasks, allowing for dynamic engagement in the Graphic Mode.

Commit 5: Implement Basic Graphic Mode Interaction (Image/Video)
